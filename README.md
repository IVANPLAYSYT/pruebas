# War of Caos 3D — GLB inventados

Esta versión ya incluye archivos GLB inventados para que puedas probarlos sin buscar modelos externos.

## Incluye
- barbarian.glb
- archer.glb
- giant.glb
- wizard.glb
- king.glb
- townhall.glb
- goldmine.glb
- elixir.glb
- cannon.glb
- archer_tower.glb
- wall.glb
- barracks.glb
- laboratory.glb

## Importante
- La demo carga esos GLB automáticamente.
- Si un modelo falla, usa el modelo procedural de reserva.
- Los GLB son inventados y sencillos, solo para probar el flujo del juego y el cargador.
